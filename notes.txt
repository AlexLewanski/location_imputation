- deal with label switching/assignment issues across EM runs and comparing estimates to true
  locations. I am dealing with this so far by using a simple, greedy matching approach where
  I pair the closest locations, and then second, third, etc. With this I also implemented some
  functionality with the EM wrapper functions to first deal with the label switching across
  runs and then exctracting the coordinate estimates that are different but result in identical
  likelihoods. For this, I use the following steps: (1) identify and extract any runs with the max
  likelihoods, (2) implement greedy matching approach using the first max lik run as the reference,
  (3) compare the estimates across max lik runs to identify and extract different estimates.
